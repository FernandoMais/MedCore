---
name: Intended outpatient use
description: The product is intended for real outpatient clinical operation, not only demonstrations.
---

The owner intends to use this system in an outpatient clinic.

**Why:** The owner explicitly asked whether the routines are sufficiently
reliable to use in the ambulatory setting.

**How to apply:** Treat clinical confidentiality, acknowledged persistence,
recoverability and authorized professional access as release requirements.
An attractive interface or a passing build is not evidence of clinical readiness.
